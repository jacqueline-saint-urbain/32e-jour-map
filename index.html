Pour les agents et les développeurs

Toutes les données de cette page sont dans des fichiers stables, sans JavaScript requis :

  • data/regles.json — source unique : arrondissements, tronçons, sources, dates
  • data/troncons.geojson — tronçons en GeoJSON (lon, lat; EPSG:4326)
  • data/arrondissements.csv et data/troncons.csv
  • llms.txt — mode d'emploi pour agents (requêtes par adresse, code postal, coordonnées)

Les mêmes données sont aussi intégrées à cette page dans <script id="donnees" type="application/json">.
